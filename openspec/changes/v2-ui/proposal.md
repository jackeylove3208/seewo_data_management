## Why

当前新建对账页面将 AI 对话、CSV 选择和任务草案挤在同一界面，用户难以区分“描述治理目标”和“接入外部数据”这两个不同工作。V2 UI 需要建立清晰的双入口工作流，并以更稳重、专业的企业工作台视觉呈现已有对账能力。

## What Changes

- 将左侧工作台的单一“新建对账”入口拆分为“新建对话”和“外部数据同步”两个主要入口。
- 让“新建对话”专注于 AI 对话和独立任务草案，不在对话中选择 CSV；用户可携带草案进入外部数据同步。
- 将现有 `/tasks/new` 操作统一命名为“外部数据同步”，直接进入时使用现有默认任务信息。
- 外部数据同步首屏只提供“手动同步”；用户选择后才显示双方 CSV、任务信息和“开始同步”操作。
- 不展示或预留自动同步入口，不增加自动同步、增量同步或外部系统 API。
- 复用现有 CSV 摘要、上传、幂等任务创建、历史刷新和成功跳转逻辑；任务创建后的数据接入、实体解析、差异检测和 AI 分析流程保持不变。
- 重构前端视觉层级、间距、色彩、排版、反馈状态和响应式布局，使界面成为安静、清晰、适合持续操作的企业数据工作台。

## Capabilities

### New Capabilities

- `external-data-sync`: 定义手动外部数据同步入口、按需展开的 CSV 任务表单、草案带入、提交状态和错误恢复行为。

### Modified Capabilities

- `reconciliation-left-workspace`: 将单一“新建对账”命令改为独立的“新建对话”和“外部数据同步”导航入口。
- `conversational-task-creation`: 从对话移除 CSV 附件和直接创建职责，使对话只生成可编辑任务草案，并将草案交给外部数据同步完成数据接入和任务创建。

## Impact

- 主要影响 `frontend/src/app/WorkspaceSidebar.tsx`、应用路由、`frontend/src/features/task-create/` 组件边界和 `frontend/src/styles/global.css`。
- 需要新增独立对话页、外部数据同步页、共享任务草案传递边界及相应单元测试和 Playwright 流程。
- 现有任务创建客户端服务和后端 API 契约保持不变；不新增后端迁移、依赖或外部连接器。
- 需要更新现有侧栏、应用导航、任务创建和端到端测试中的可见文案与交互断言。
