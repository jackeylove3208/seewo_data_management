# Sample data

The repository root contains the current deterministic UTF-8 fixtures:

- `third_party_data.csv`: authoritative source, 515 data rows.
- `mofa_data.csv`: Seewo/Mofa governance target, 518 data rows.

Both are mixed-entity CSV files with the mapping profile columns `entity_type,id,name,parent_id,grade,class_name,subject,phone,email,extra`. They contain synthetic departments, classes, teachers, and students generated by `生产数据.py`; no production records are permitted here.
