# 答辩演示 HTML 视觉与动效重设计

## 背景

目标文件 `AI组织架构数据治理系统-实习课题答辩-v2.html` 已具备完整的 18 页答辩内容、流程图、代码片段和案例截图，但目前主要依赖 slide 级横向淡入，页面内元素缺少层次化入场，翻页状态也容易留下旧的动画状态。用户提供的参考文件 `智能数据导入模块_演示_飞书 (1).html` 采用浅色卡片式视觉、统一的蓝绿强调色、逐元素 `fadeUp/scaleIn` 动画、错峰延迟和轻量悬浮反馈，作为本次重设计的风格基准。

## 目标

- 保留目标页现有 18 页内容、文案、图片、代码和信息结构。
- 将参考页的视觉语言迁移到目标页：浅灰背景、白色卡片、蓝绿主色、统一圆角、细边框和柔和阴影。
- 建立可复用的逐层入场动画，使标题、分隔线、正文容器和内容卡片按阅读顺序出现。
- 保证每次翻页都能可靠重播当前页动画，避免动画只在首次加载时播放或被旧状态污染。
- 保留键盘、空格、点击左右区域、上一页/下一页按钮和触摸滑动操作。
- 在不影响内容可读性的前提下，增加适度的悬浮反馈与封面氛围动效。

## 非目标

- 不改写 18 页的业务叙事、文案、图片素材或代码示例。
- 不引入框架、打包工具、外部 CDN、运行时依赖或新的后端接口。
- 不将页面改造成需要滚动浏览的长页面；桌面端仍以单页演示为主。
- 不使用高频粒子、连续大幅视差或复杂 3D 动画，避免抢夺答辩内容注意力。

## 设计方案

### 1. 视觉基线

沿用参考页的轻量产品演示风格：页面背景使用 `#F7F8FA`，卡片使用白色，主色为蓝色与绿色，紫色、琥珀色和红色只用于表达不同阶段或风险状态。卡片统一使用约 16px 圆角、1px 边框和低对比度阴影，hover 时只提升 4–6px 并增强阴影，不改变布局尺寸。

封面保留现有左右结构，但增加不干扰文字的蓝绿径向光晕和轻微漂浮装饰层；标题、说明、旅程标签、右侧能力卡和作者信息按顺序进入。其余页面保持现有的 section tag、居中标题和内容区域，重点通过层级、留白和动效增强阅读路径。

### 2. 动效系统

建立三类基础动画：

- `fadeUp`：内容从下方 20–28px 进入并淡入，用于标题、说明、卡片、代码块和流程节点。
- `scaleIn`：分隔线从中心横向展开，用于标题下方的视觉锚点。
- `float`：只用于封面氛围装饰与少数非关键信息元素，低频、低位移、可关闭。

每个 active slide 在进入时触发一次新的 reveal 周期。实现上由脚本为当前页的可动画元素写入顺序索引，再通过 CSS 自定义属性计算 60–90ms 的错峰延迟；离开页面时清除当前页的 reveal 状态，返回页面时重新初始化。这样既能保持 HTML 结构不变，也能避免把动画延迟硬编码到 18 页内容中。

页面切换使用参考页风格的 `opacity + translateX` 过渡，动画曲线统一为平滑的 cubic-bezier；上一页、下一页和跳转到首页/末页都通过同一 `goTo` 状态入口，确保 active/prev 类和动画重置逻辑一致。

### 3. 组件级反馈

- `.panel`、`.trade-card`、`.arch-card`、`.issue-card`、`.principle` 等卡片增加一致的 hover elevation 和边框色反馈。
- 流程箭头、状态标签和风险色块保留原语义，不对其做持续闪烁；只在进入时做一次轻量淡入。
- 代码面板、流程图和截图容器采用更明确的层级阴影，避免整个页面所有元素同时发光。
- 底部进度条改为参考页的 4px 渐变条；左右按钮改为圆形浅色按钮，hover 时使用主色边框和文字，禁用态保持低对比度。

### 4. 响应式与可访问性

继续遵守现有的 1100px、850px 和 780px 断点：桌面端保持演示比例，小屏幕允许 slide 内部垂直滚动，并隐藏非必要的键盘提示。所有动效包裹在 `@media (prefers-reduced-motion: reduce)` 降级规则下，降低为即时显示和无位移切换；按钮保留原生 focus-visible 轮廓，图片保留 alt 文本。

## 实现边界

实现集中在目标 HTML 文件内：

1. 调整现有 CSS 变量、基础卡片样式、导航样式和 slide transition。
2. 增加基础 keyframes、reveal 选择器、hover/focus 状态、封面装饰层和 reduced-motion 规则。
3. 在现有导航 IIFE 中增加动画初始化/清理函数，并让 `goTo` 负责统一刷新 UI 与 reveal 状态。
4. 保留现有 DOM 结构；只有在封面装饰或导航反馈需要时增加最小的语义化元素。

## 验收标准

- 打开 HTML 后，封面标题、说明、标签和右侧卡片能够按顺序进入，首屏不出现内容闪烁或永久透明。
- 从任意页前进、后退、跳转首页和跳转末页时，当前页的元素动画都能重新播放一次；离开页不会覆盖当前页。
- 18 页内容、图片路径、代码文本和底部来源信息保持完整可读。
- 卡片 hover、导航按钮 hover/focus、进度条和翻页过渡视觉一致，没有布局抖动。
- ArrowLeft、ArrowRight、Space、Home、End、按钮、左右点击区域和 touch swipe 均可用，且不会误触页面内链接或按钮。
- `prefers-reduced-motion: reduce` 下不执行明显位移动画，页面仍可正常翻页。
- 使用静态检查确认 HTML 标签闭合、脚本语法和关键选择器存在；通过本地渲染检查首屏、代表性内容页和收尾页的布局与动画状态。

## 风险与取舍

- 18 页内容密度较高，过多 stagger 可能让答辩节奏变慢；动画只用于首次进入，单个 slide 的总延迟控制在约 1 秒内。
- 目标文件当前为单文件演示，保留单文件实现有利于直接双击运行，但会让 CSS 继续集中在 HTML 中；本次只做局部整理，不做无关拆分。
- 本地 file URL 在当前内置浏览器环境中受访问策略限制，验证阶段优先使用源码/脚本静态检查与可用的本地渲染路径；如果环境仍不能提供页面级渲染，则在交付中明确说明实际完成的视觉验证范围。
